# Short-Form Scripts: 26 Oct – 20 Nov 2026

## The structure (every script)

1. **HOOK**: Context lean → "But…" interjection → contrarian snapback. On-screen text (3–5 words), first visual and spoken hook all say the same thing. First value within 4 seconds. [Kallaway, Jatho]
2. **TRUST ANCHOR**: one true proof line in lines 2–3. "How I / How we." [Kallaway, Hormozi]
3. **VALUE LOOP**: Context → Value → Context → Value. "But" only for a real problem; "So / Therefore / That way" when it follows. Never "and then." Value = clear, actionable steps. [Kallaway, Hormozi: Power]
4. **IMMEDIATE WIN**: one result they can get today. [Hormozi: Power]
5. **CTA → LAST DAB**: one sentence. The CTA flows into a last line that loops back to the hook. [Kallaway, Jatho, Hormozi]

## CTA rules this month

- **Free audit**: one pool of **10 audits total** across all videos. When spots run out, say so in later videos. Never fake scarcity.
- **Direct access**: "DM me [WORD]. I read every message myself."
- **Free install**: free setup for 5 businesses in exchange for filming it.
- **No ask**: value only.
- Every video has its **own keyword**, so you can track which video brings DMs, audits and calls.

## Before filming any script

- **Trust anchor**: say it only if it's true. Every script has a fallback line.
- Read it out loud once. If a line doesn't follow from the one before, reword it.
